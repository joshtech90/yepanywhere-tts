# Chrome extension changelog

## [0.1.3] - 2026-10-14

- Open the app in popup windows and from the toolbar context menu.
- Start sessions in a dedicated window and show a session's issues in the side panel.
- Remember collapsed side-panel groups and new-session defaults.
- Fix queued-message recall, attachment draft synchronization and production diagnostics.

## [0.1.1] - 2026-10-13

- Initial public client, side panel, related-session lookup and optional site badges.
