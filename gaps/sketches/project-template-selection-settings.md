# Template settings shown during selection

User direction, 2026-09-28: templates may eventually declare settings shown
when selected, such as audience and additional instructions. Keep this UI and
its manifest schema as a sketch; they are not part of the approved immediate
implementation.

Administrator controls are separate: choosing whether a limited user imports
standard harness-global instructions into its private home, and editing
instructions before/after template setup, are approved work tracked in
[template stand-up](../project-template-standup.md).

Canvas's immediate content default is child-friendly: present mockups of the
requested visual parts, ask one understandable approval question, wait, and
then build on an affirmative answer. A future audience setting could adjust
language and interaction style without changing access grants or inheriting
the administrator's personal agent instructions.

Open design questions: which settings the administrator fixes versus permits
the user to change, source/schema validation, persistence with project intent,
and presentation for children. No new selection controls are implemented.
